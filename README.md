# CBG Agri Innovation Hub

A modern single-page React website for CBG Agri Innovation Hub, built with Vite, TypeScript, Tailwind CSS, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The site includes:

- Responsive navigation and single-page sections
- Auto-advancing field-story slideshow with captions
- CBG brand logo and agriculture-focused visual system
- Gallery using CBG photos from the field
- Upload controls for replacing gallery images in the browser
